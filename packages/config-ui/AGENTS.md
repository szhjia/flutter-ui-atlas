# 正式配置页约定

- 这是 `atlas config` 的正式桌面页面，通过 ConfigAdapter 访问本机服务；禁止演示登录替代真实认证。
- 保留已经确认的左侧角色表格、右侧编辑栏及原有信息层级。启停只在列表提供，RoleDraft 不携带 enabled。
- 账号仅由本机凭据读取接口提供，已有密码只提供 passwordSet，编辑留空保持；不得把密码写入 URL、浏览器存储、日志或错误信息。
- 应用登录方式全局配置一次；未知表单不能靠猜测判为成功。
- 服务断开后禁止写入并保留草稿，保存错误反馈保留可行动原因。
- 不修改 Viewer 的公共卡片内部契约，不新增手机端断点。原型的历史设计记录保存在 docs 中。
