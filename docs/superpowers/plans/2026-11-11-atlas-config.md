# atlas config 正式接入实施计划

依据：2026-11-11 用户批准的 config 计划及本地配置与多角色自动采集设计。本轮仅实现 config，不接入多角色 build 或收缩 Viewer。

- [x] 先定义共享配置、RoleDraft、AuthenticationAdapter 与脱敏读取契约。
- [x] 实现官方 YAML 与本机凭据存储、串行操作、权限、Git 跟踪拒绝、事务恢复、并发冲突。
- [x] 实现通用表单/MJS 认证、凭据快照与 checkId、本机 HTTP 服务、CLI 自动打开与关闭。
- [x] 迁移已确认界面，补登录设置、删除、断开与失败反馈，接根构建和安装包。
- [x] 生产实现完成后补单元及集成测试，再集中运行类型、全套测试、浏览器与打包验证；批量修复。
- [x] 验证独立 Flutter 登录入口及隔离安装；验收后删除原型、迁移记录，完成一次独立只读审查。

默认配置页端口由系统分配；Chrome 测试上下文独立，15 秒超时；API 请求体最多 64 KiB。用户名、密码、测试记录仅在 .atlas/local，目录 0700/文件 0600。YAML 保留未知字段和注释。旧 JSON/MJS 不被自动改写，不能无损接入时明确拒绝。启停仅列表修改，角色保存不得携带 enabled。最终不自动提交、推送或发布。
