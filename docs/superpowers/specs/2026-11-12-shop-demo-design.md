# 普通商城 Demo 与通用 Atlas 接入设计

日期：2026-11-12。本文按用户最新批准范围替代本文件早期的专用入口方案；不提交、推送或发布。

## 目标与边界

`demo/` 是可独立复制运行的普通 Flutter 工程，只有 `lib/main.dart`；没有 Atlas SDK、专用场景入口或生产 `scripts/shop-*` 编排依赖。Atlas 只连接已运行的 Web 服务，不执行 Flutter 命令、不构建或启动应用。根开发入口 `pnpm dev` 只启动 Node／React 画布，无需 Flutter SDK。测试 harness 可为验收自行编译、启动普通 Demo，不进入产品接入链路。

整个工程 `.atlas/` 是本机私有目录，根 `.gitignore` 维护 `/.atlas/`；配置、凭据、私有快照和产物不提交。已有跟踪内容先报告，由用户自行取消跟踪，工具只读索引。不得跟随根忽略文件符号链接，不得以回滚覆盖用户的新内容。

## 应用能力

- user1、user2，密码均为 1234.com，权限相同；先登录再使用，退出后保护路由禁止返回。
- 首页、商城、我的；6 个本地商品、参数化详情、购物车增减删除、整数分合计，无后端、订单或支付。
- 本地登录和各账户购物车持久化；退出不清空购物车，确认后可重置演示数据。失败保护内存状态并告知，损坏内容不静默覆盖。
- 小于 720 逻辑像素用底部导航，其余用侧边导航；基准视口 phone 393×852、pad 1024×768。画布 Viewer 仍仅面向桌面窗口。

## 通用配置和采集

账户由 `atlas config` 配置页维护，用户名与密码只在本机私有文件保存。YAML 负责 `profiles`、`screens.roles`、`prepare`、`ready.all` 和 `edges.steps`，描述视口、账户选择、真实状态准备、全部就绪判据与实际操作。

账户拥有稳定 UUID；页面模板使用稳定 ID，展开页面以账户 UUID 和模板 ID 组合，不以显示名或 Tag 派生身份。修改账户显示名不能破坏页面与布局关联。匿名身份使用保留标识。

构建读取固定的私有快照，绑定配置、账户和凭据版本；后续编辑不改变已读快照，变化后拒绝以旧快照启动新操作。公开 manifest 和 Viewer 配置不暴露凭据。每个 profile 独立输出；只有真实操作、目标路由和目标内容均成立，连线才是 observed。失败保留上一成功图谱并记录报告。

## 实时操作

由工具创建独立 Chrome 上下文，按成功采集对应的私有快照登录、复现并验证选中页面。取消、替换、手动关窗与服务退出统一回收资源；旧请求不能关闭新会话，迟到资源不得泄漏。

应用无需识别场景参数或管理 Atlas 内存会话。旧 iframe／SDK 接入可选兼容，不能作为普通工程必需条件。浏览器上下文隔离不代表服务器端业务数据自动隔离。

## 验收

验收必须覆盖普通 Demo 独立复制测试与构建、根忽略文件及已有跟踪拒绝路径、快照变更失效、声明式多账户两视口采集、真实登录与操作证据、失败保留好图、工具 Chrome 会话隔离和资源清理。完整 CLI 与真实浏览器闭环尚待本轮最终验证，分项通过不等于任务完成。
