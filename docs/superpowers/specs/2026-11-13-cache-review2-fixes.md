# 认证依赖与发布恢复遗漏修复

沿用上一轮审查的三个临时项目复现，按 systematic-debugging 追踪根因；遵循工程后端顺序，完成实现和回归作者工作后集中验证。保留既有未提交修改。

## 修改

1. 使用锁定版本 es-module-lexer 2.3.2 解析 ESM 导入与转导出，替代正则提取。支持注释、转义说明符、字面量动态导入；不确定的动态依赖和无法解析的语法禁止复用。解析器登记为直接运行依赖，doctor 与独立安装检查同步覆盖。
2. 原子索引写入支持替换前校验：索引临时文件写好后重新计算源码依赖、核对配置和凭据，再替换索引。发现源码变化时保留旧索引，写失败报告，并清理临时文件。
3. 非权威 build-state 缓存 JSON 损坏或结构无效时降级为缓存未命中。普通构建和 force 可重新采集，成功后建立可复用的新缓存；权限与其他真实 I/O 错误仍不被吞掉，正式索引不按缓存损坏逻辑忽略。

## 回归证据

- 依赖词法用例覆盖带注释的静态导入/转导出、转义路径、字面量动态导入、伪导入字符串与注释，以及不确定动态依赖和无效语法。
- 真实 Chrome 认证模块 helper 变化后拒绝旧实时快照，构建不命中旧缓存；失败保留旧地图，恢复原 helper 可复用旧成功版本。
- 在索引临时文件写好后注入源码变化，构建失败且索引逐字不变；恢复源码后旧缓存仍可复用。
- 截断缓存 JSON 下 force 成功重采；错误 records 结构下普通构建成功重采；重建后再次命中保留 captureId。
