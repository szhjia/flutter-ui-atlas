# 桌面画布工作区打磨

用户通过六处页面批注要求浮动布局工具、固定宽度搜索、详情调宽、居中释义、合理缩放与有限平移，以及更均衡的自动布局。详情面板已确认采用拖动左边界调宽，仍停靠右侧。

## 工作区与交互

- Header 保持 56px；搜索固定 240px，视图与布局操作放回画布。
- 布局工具浮于画布顶部中心，完整复用原 CanvasToolbar。额外提供 Balanced layout、Horizontal flow、Vertical flow；选择预设立即整理，可撤销。原整理确认流程保留。
- 左下缩放工具、底部居中释义与顶部布局工具使用同一白色、边框、圆角和阴影外框，基于 shadcn Button、Select、Checkbox、Separator、Tooltip 组合。缩放与缩略图略抬高，避免与居中释义重叠；无法路由的连线保留可见计数和解释。
- 详情面板默认 354px，实时预览默认 440px；用户调宽后在当前会话保持所选宽度。最小 320px、最大 720px，同时至少保留 520px 画布。支持键盘方向键、Home／End 和双击恢复默认；隐藏后保留宽度。
- 画布浮动控件、弹层与调宽手柄隔离节点移动快捷键。整理确认 Esc 可取消，命令禁用或卸载时恢复可操作焦点。

## 缩放与视口

保留原默认缩放 0.65 作为产品的 100% 基准，允许 50%–200%（引擎缩放 0.325–1.3）。百分比按钮一键恢复默认；适应视图也遵守范围，大图通过有界平移查看，不以无限缩小换取全图。旧存储仅归一化超限缩放，保留节点坐标、锁定与原始记录的有效性。

平移使用全部布局节点的内容包围盒，加 480 个画布单位留白作为有限边界。筛选不重排或重置镜头；视口尺寸、恢复旧视口、主动缩放与适应视图统一遵循边界。节点仍可拖动，边界随实际内容更新。

## 自动布局

原算法按有向层级横排，强连通循环落在同一列，导致长链过宽、大循环过高。均衡模式沿用连通分量和层级顺序，按画布纵横比选择行列并换行；横向和纵向模式保留流程阅读方向。锁定和隐藏节点不移动，邻近避让和冲突规则仍有效。已有手动布局不自动覆盖。

交互参考：Figma 的适应视图和默认缩放入口、tldraw 的相机基准与边界，以及 React Flow 的 translateExtent。没有更换画布引擎。

## 保护与验收

ScreenCard、GroupSelect、CanvasToolbar 内容与本阶段基线一致；不改变内部信息、尺寸和外观。组件、旧缩放迁移、布局、三种桌面窗口、工具条中心与边界、面板调宽、快捷键、全部既有采集失败路径与真实 Demo 均纳入验证。保持桌面限定，不新增手机断点，不提交或推送。

首轮浏览器发现 Header 下拉被浮动工具遮挡，已调整 Header 外层层级，原分组组件未改动。最终结果及截图记录于本机 .runtime/canvas-workspace。
