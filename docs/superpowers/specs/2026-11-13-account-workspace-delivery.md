# 账户工作空间重构交付记录

日期：2026-11-13。对应已批准的 B 方案与同日实施计划。

## 结果

- 稳定 application UUID、account UUID 与 profile 组成独立空间；一次只显示一个账户。布局、镜头、布局锁、选择及筛选按空间隔离，切换释放实时会话；撤销历史在本次 Viewer 生命周期内跨切换保留。
- 默认复用输入未变且资源校验完整的成功 revision，保持原 captureId 与 capturedAt；`atlas build --force` 重新采集。匿名公共证据可共享，账户节点及关系保持隔离。
- 应用级写锁、不可变 revision 与原子索引发布覆盖多账户/视口。失败保留旧成功地图，失败报告独立；命中缓存无需打开浏览器，改显示名称不改变身份。
- 源码、资源、配置、账户认证与本地认证模块依赖参与私有指纹。依赖无法可靠追踪时禁用复用，并拒绝不可靠的实时快照；Viewer 状态定期按空间检查。
- 可选 pageName 透传，未声明时使用原有名称，不推断 Dart 类名。卡片保留路由和完整等比截图，开放箭头、隐藏端点、分散双向及多条连线；保留异常提示。
- `atlas doctor` 检查 Node、模块、预构建 Viewer、Chrome、配置、身份、输出目录、应用 URL 及输入覆盖，提供英文修复建议。

## 采集与安装边界

采集使用包内 Playwright，通过 Chrome 独立上下文管理登录、页面准备和就绪检查，截图并执行声明的导航操作。只有实际操作及目标内容就绪后，连线才标记 observed。Atlas 只连接已经运行的 Web 地址，不构建或启动 Flutter 应用。

安装包携带 JavaScript 运行依赖和 Viewer 静态产物；宿主仍需要受支持的 Node 和已安装 Chrome。Atlas 不自动下载浏览器，不依赖 Flutter SDK。独立包验收禁用 NODE_PATH，核对 playwright/yaml 从临时安装目录解析，CLI 的 PATH 中没有 Flutter。

缓存仅代表过去成功采集的证据，不保证远端数据库、服务或时间未变化；需要最新运行结果时使用 force。旧 v1 manifest 保持可读，旧全局布局不自动混入新空间。
