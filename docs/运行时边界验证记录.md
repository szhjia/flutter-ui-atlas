## 破坏性变更说明

- 数据配置（yaml/json）的非回环 `baseUrl`/`preview.origin` 现在默认拒绝——这是有意的边界统一（与 `--url` 既有口径一致），逃生口 `allowRemoteUrls: true` 与协议说明已提供。使用局域网开发服务的既有接入方需加一行配置。
- preview origin 的 view() 分支未做常驻 server 端到端断言（见台账已知缺口），由共享助手单测与回归覆盖。
