## Flutter 输入就绪回归

最终隔离包复验定位了 Flutter 输入时序：DOM focus 已发生，但框架要在后续语义更新才挂接 input 订阅；过早 fill 会丢失输入。直接流程 6 次有 3 次失败，仅使用 Tab 未解决。适配器现只对 Flutter 语义字段等待渲染更新，填入后等待框架消费，提交前验证字段保留输入，不记录值，也不自动重试密码提交。真实 Flutter 连续 6/6 通过，新增延迟输入订阅的 Chrome 回归通过。

可重复运行：先构建并提供独立 config_login.dart 的 Flutter Web 服务，再执行 `node examples/verify-config.mjs <示例地址> [安装包中的 atlas.mjs 路径]`。脚本连续验证三次成功登录，再验证错误密码、匹配结果保存、CLI 重启、权限和脱敏读取及删除。只使用虚构账号与临时工程，不读取接入方 fixture。
