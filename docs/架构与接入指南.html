DEVELOPER GUIDE / 0.1.0

Flutter UI Atlas
接入指南

在开发机装好 Atlas CLI，即可从普通 Flutter Web 入口采集界面图谱。需要监听应用内部导航时，再接入 Dart SDK。

01 / ARCHITECTURE

从 Flutter Web 到画布

采集器在独立的 Chrome 会话中访问页面，等目标内容就绪后截图。验证连线时，采集器会实际点击来源页上的按钮，确认目标路由和内容后才标记为 observed。

CLI 和采集器
flutter-ui-atlas npm 安装包包含预编译 Viewer。当前版本从源码打包。
Viewer
用 atlas view 打开独立画布，也可在 React 工作台中本地引用 @flutter-ui-atlas/viewer。
Dart SDK
flutter_ui_atlas 是独立本地包，提供导航监听、场景准备和就绪接口。
02 / QUICK START

跑一次「项目列表 → 项目详情」

准备 Node.js、pnpm、Flutter SDK、Python 3 和 Google Chrome。Atlas 仓库的 Node 版本见 .nvmrc。

  1. 01

    安装 Atlas CLI

    在 Atlas 仓库根目录运行。

    Atlas 仓库 
    pnpm install --frozen-lockfile
pnpm run pack:cli
npm install --global .runtime/packages/flutter-ui-atlas-0.1.0.tgz
  2. 02

    启动 Flutter Web

    在 examples/flutter_app 运行，保持终端打开。

    Flutter 示例 
    flutter pub get
flutter build web --debug --no-web-resources-cdn --target lib/main.dart
python3 -m http.server 60210 --bind 127.0.0.1 --directory build/web
  3. 03

    采集并打开画布

    另开终端，回到 Atlas 仓库根目录运行。

    Atlas 仓库 
    atlas build --config examples/atlas.config.json
atlas view --config examples/atlas.config.json --port 60322

打开地址。 等 atlas view 打印地址，再访问 http://127.0.0.1:60322/。画布打不开时检查 atlas view，画布里的实时预览打不开时检查 Flutter 服务和配置里的 baseUrl。

接入自己的应用。 在 Flutter 工程根目录运行 atlas init，按提示生成 .atlas/atlas.yaml。启动 Flutter Web 后运行 atlas build 和 atlas view。结果默认写入 .atlas/generated/。多页采集可参照示例填写路由、ready 和 click。示例配置 · 协议与适配接口

04 / OPTIONAL SDK

按需注入导航监听

在应用的 pubspec.yaml 中，将 flutter_ui_atlas 加入 dev_dependencies，用 path 指向 Atlas 仓库中的 SDK。新增 lib/main_atlas.dart，通过应用构造函数把 observer 传给 MaterialApp.navigatorObservers。示例依赖

lib/main_atlas.dart 
import 'package:flutter/widgets.dart';
import 'package:flutter_ui_atlas/flutter_ui_atlas.dart';
import 'main.dart';

void main() {
  WidgetsFlutterBinding.ensureInitialized().ensureSemantics();
  runApp(ExampleApp(observers: [
    AtlasNavigatorObserver((route) => debugPrint('ATLAS_LOCATION:$route')),
  ]));
}

调试时用 --target lib/main_atlas.dart 启动专用入口。这个 observer 将命名路由事件写入日志，截图和连线验证仍由浏览器完成。SDK 入口源码
