# Bundled font

Noto Sans SC is distributed under the SIL Open Font License 1.1. See [OFL.txt](OFL.txt) for the full license.

The demo keeps its own font copy so text rendering does not depend on a font CDN or another project. The file was copied from an existing local Noto Sans SC asset. It includes Latin glyphs and is retained for consistent rendering of the English demo.
